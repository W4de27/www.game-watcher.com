# 🎮 GameVault – PC Games Download Platform

> A modern and interactive platform to explore, preview, and download top PC games with a clean and engaging user interface.

---

## 🚀 Project Overview

**GameVault** is a stylish web platform designed for gamers to discover and download PC games easy way. It provides a structured and user-friendly interface where users can browse games, view essential details, and access real download options.

Built using pure HTML, CSS, and JavaScript, this project focuses on delivering a smooth browsing experience combined with practical functionality.

---

## ✨ Features

- 🎮 Browse a collection of PC games
- 📥 Real download access for games
- ⭐ Game ratings (user stars)
- 💾 Display of installation size
- 🔎 Clean and structured game cards
- 🔄 Pagination / Load more functionality
- 🧭 Easy navigation system
- 📩 Functional contact section

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

---

## 🎨 UI Highlights

- Modern gaming-inspired design
